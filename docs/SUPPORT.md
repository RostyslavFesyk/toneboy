# toneboy Support

toneboy is a system audio equalizer for macOS 14.2 and later. Open it from the icon in your menu bar.

If toneboy cannot start processing, open its menu, choose **Audio Access Settings…**, and allow system audio recording. Return to toneboy and choose **Try Again**. Use your Mac speakers or stereo headphones. The equalizer switch turns processing off and restores normal playback.

For support, questions, or feature requests, email [rostyslavfesyk@gmail.com](mailto:rostyslavfesyk@gmail.com). You do not need a GitHub account to contact us.

You can also [open an issue](https://github.com/RostyslavFesyk/toneboy/issues/new). Include your macOS version, output device type, and the steps to reproduce the problem. Issues are public. Please omit private information and audio recordings.
